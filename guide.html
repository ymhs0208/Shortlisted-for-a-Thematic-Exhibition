海報怎麼做？

先準備專題的編號、班級、名稱，以及一張海報圖片。第一次使用，可以先試做一張。

我只想做一張我有很多張要做

只做一張海報

在製作室左側點「單筆編輯」，依序完成下面四步。

  1. 填寫專題資料

    點進欄位，依序輸入 編號、班級、專題名稱。直接輸入就會建立第一筆。要做下一組時，再按「新增一筆」。

  2. 從電腦選海報圖片

    按「選擇海報圖片」。在跳出的視窗裡，到「下載」或「桌面」找到圖片，點一下檔案，再按「開啟」。

    選成功後，右側「海報預覽」會出現圖片。

  3. 選版面並確認內容

    在「海報預覽」右上角按「選擇模板」，點一下喜歡的縮圖。確認編號、班級、名稱和圖片都正確。

  4. 把做好的海報存下來

    按預覽下方的「下載這張 PNG」。PNG 是圖片檔。下載後，通常可在電腦的「下載」資料夾找到它。

一次做多張海報

準備一份 Excel 名單和每組的圖片。以下用兩組示範檔名怎麼對應。

  1. 先排好 Excel 名單與圖片檔名

    第一列寫欄位名稱，下面每列填一組。將圖片檔名改成專題編號，就可以留空「海報檔名」欄。

    編號班級名稱
    A01資管四甲智慧步態分析
    B02多媒四乙校園導覽設計
    例如 A01 的圖片叫 A01.png，B02 的圖片叫 B02.jpg。圖片另存成檔案，放在同一個資料夾會比較好選。

  2. 把名單放進製作室

    在左側點「批次匯入」，再點「匯入 Excel 或 CSV 資料表」，選取 Excel 檔（.xlsx），再按「開啟」。匯入成功後，會在「製作清單」看到各組。

  3. 一次選取所有海報圖片

    按「批次選擇海報圖片」。按住鍵盤上的 Ctrl，依序點選各組圖片，再按「開啟」。如果系統找到多張同編號圖片，請在彈窗選一張。

    若有「缺少圖片」，點清單上的該組，回到單筆編輯補上圖片。

  4. 確認模板，再下載整批海報

    選好模板後，按頁面上方的「下載全部 ZIP」。到「下載」資料夾找到 ZIP 檔，在 Windows 用滑鼠右鍵點它，選「解壓縮全部」。海報會按領域分到不同資料夾。

遇到問題怎麼辦？

海報邊緣被切掉了

把「圖片配置」改為「完整顯示（留白）」，畫面會保留整張圖片。

下載時提示有海報沒匯出

看提示裡的專題編號和原因，回清單找該組，補齊編號、班級、名稱或圖片，再下載。

Excel 匯入失敗

檢查第一個工作表的第一列有沒有寫「編號、班級、名稱」，每組是否都有填這三欄。也可以按首頁的「下載匯入範本」，依範本填寫。

下一次打開還能繼續做嗎？

請用同一台電腦、同一個瀏覽器和同一個網址。系統會在這個瀏覽器儲存資料。換電腦時，請帶上原始名單和圖片。
