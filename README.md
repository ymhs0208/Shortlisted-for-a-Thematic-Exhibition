# 專題成果展海報製作系統

「海報製作室」是一套以瀏覽器操作的專題成果展海報工具。可逐筆建立或批次匯入專題資料、加入海報圖片、即時預覽版面，並輸出單張 PNG 或整批 ZIP。另提供圖片相簿，方便檢視素材與製作完成的海報。

## 功能特色

- **單筆編輯與即時預覽：** 編輯編號、專題名稱、班級和海報圖片；預覽畫布為 1920 × 1080 px。
- **批次匯入：** 支援 Excel（`.xlsx`，讀取第一個工作表）、CSV、TSV，以及直接貼上試算表資料。CSV 支援 UTF-8 與 Big5。
- **批次配對圖片：** 不依副檔名限制，改由瀏覽器實際解碼並驗證可用於海報輸出的圖片；依「海報檔名」或編號的檔名主體配對。同一編號有多張圖片時可選擇，無法處理的檔案會逐一列名。單筆手動上傳的圖片不會被批次配對覆蓋。
- **清單管理：** 搜尋專題資料並依編號、專題名稱、班級或圖片狀態排序；單筆刪除可復原，清除全部資料前會再次確認。
- **圖片相簿：** 搜尋並切換檢視原始專題圖片或製作完成的海報；點選卡片可回到該筆資料編輯，亦支援手動與自動幻燈片播放。
- **海報輸出：** 下載目前海報為 PNG，或將可匯出的海報打包成 ZIP。輸出前會檢查必填欄位與實際圖片；未通過檢查的項目會列出原因。
- **領域數量統計：** 依專題編號首碼分類統計。

## 開始使用

本專案是靜態網頁，無須安裝套件或建置。建議從專案根目錄啟動本機 HTTP 伺服器，再以瀏覽器開啟：

```bash
cd /path/to/Shortlisted-for-a-Thematic-Exhibition
python3 -m http.server 8000 --bind 127.0.0.1
```

接著前往 <http://127.0.0.1:8000/>。若要停止伺服器，在終端機按 `Ctrl+C`。請保留 `assets/`、`css/`、`js/`、`vendor/` 與三個 HTML 頁面，版型、預覽與 Excel 匯入才會正常載入。以 HTTP 開啟時，模板直接讀取 `assets/` 裡的圖片，不需要額外產生檔案。

若用 `file://` 直接開啟頁面，Chromium 會把每張模板圖視為不同來源，畫布被污染後就無法匯出。這時才需要把模板嵌成 data URL。產生的 `assets/local-template-images.js` 約數 MB，不納入版本庫；模板圖片更新後再執行：

```bash
node scripts/embed-local-templates.mjs
```

## 建議操作流程

1. 開啟「單筆編輯」逐筆輸入資料，或切換到「批次匯入」載入資料表。
2. 批次匯入時，第一列需包含欄位名稱；必要欄位為「編號」、「名稱」及「班級」，「海報檔名」為選填。舊欄名「代碼」也可用於編號欄。
3. 如有重複編號，依提示選擇「全部新增」、「覆寫重複資料」或取消匯入。覆寫會更新相同編號的表格欄位；既有手動上傳圖片會保留。
4. 上傳海報圖片。可在單筆編輯中選擇一張，或在批次匯入中一次選取多張；批次圖片依海報檔名配對，未填檔名時改依編號配對，忽略副檔名；同一編號有多張候選圖片時會請你選擇。瀏覽器無法解碼或無法安全輸出的檔案會列出檔名。
5. 在製作清單確認圖片狀態，點選資料檢查即時預覽，並選擇「完整顯示（留白）」或「填滿（裁切）」。
6. 下載單張 PNG，或使用「下載全部 ZIP」輸出符合條件的海報。只有實際加入的圖片可供匯出。

可使用「下載匯入範本」取得 CSV 欄位範本。每次最多管理 500 筆資料；單筆「新增一筆」與批次匯入都受此上限限制。

## 資料與隱私

專題文字、圖片及匯入狀態會自動儲存在目前瀏覽器的 IndexedDB，不會由本系統上傳至伺服器。資料只屬於目前瀏覽器與網站來源；換瀏覽器、裝置或網站網址不會自動同步。清除瀏覽器網站資料也可能一併移除已儲存內容。請妥善保管原始資料與圖片檔案；海報 PNG／ZIP 可作為成品輸出，但不是可重新編輯的資料備份。

「刪除全部資料」會清除此瀏覽器中的專題資料與匯入圖片，並且無法復原；執行前請確認。

## 專案檔案

頁面仍是靜態 HTML，樣式與程式拆到 `css/`、`js/`，以 `<script type="module">` 載入，不需要框架或建置。頁首與頁尾的 HTML 留在各頁：導覽連結不同，而且使用教學頁不依賴 JavaScript。

- `index.html`：海報製作室與資料管理介面。
- `gallery.html`：圖片相簿與幻燈片。
- `guide.html`：網頁版操作指南。
- `css/`：設計變數、頁首、頁尾、三個頁面與窄螢幕版面。
- `js/db.js`：製作室與圖片相簿共用的 IndexedDB（資料庫 `thematic-exhibition-poster-studio`，物件存放區 `state`，鍵值 `app`）。
- `js/poster-renderer.js`：六種海報版面的繪製與預覽。
- `js/import.js`、`js/export-zip.js`：匯入解析與 ZIP 打包，可在沒有瀏覽器的情況下測試。
- `js/studio.js`、`js/gallery.js`：兩個頁面的操作邏輯。
- `assets/`：六張海報模板圖。
- `vendor/xlsx.full.min.js`：本機使用的 Excel 試算表解析程式。
- `scripts/embed-local-templates.mjs`：產生 `file://` 用的模板嵌入檔。
- `系統使用說明書.pdf`：使用說明書。

純函式測試不需要安裝套件：

```bash
node --test
```
